# Karro — платформа пошуку та бронювання СТО

Навчальний проєкт: вебплатформа, що з'єднує автовласників із станціями технічного
обслуговування. Клієнт веде цифровий гараж, записується на ремонт через календар
робочих боксів і спілкується з майстернею в чаті заявки. Власник СТО керує
заявками, розкладом, складом запчастин і бухгалтерією.

## Можливості

- Реєстрація двох типів користувачів: клієнт та адміністратор СТО
- Цифровий гараж авто з розшифровкою VIN-коду (NHTSA API + локальний словник WMI)
- Пошук СТО на карті (Leaflet) із фільтрами за містом, послугою, рейтингом та радіусом
- Бронювання за тайм-слотами з урахуванням графіка роботи, обіду та зайнятості боксів
- Чат заявки з узгодженням додаткових робіт і фото несправності
- Автоматична історія обслуговування автомобіля після завершення ремонту
- Кабінет СТО: послуги, бокси, графік роботи, співробітники
- Бухгалтерія: доходи/витрати, зарплати з комісіями, склад запчастин,
  експорт звітів у Excel та PDF
- Адмін-панель (Django Unfold) з верифікацією СТО та блокуванням користувачів
- Українська/англійська локалізація інтерфейсу, темна тема

## Стек технологій

- Python 3.9+ (перевірено на 3.9 та 3.11), Django 4.2 LTS (чистий MVT, без важких сторонніх REST-фреймворків)
- MySQL / SQLite (для локальної розробки та тестування перемикається прапорцем USE_SQLITE=True)
- Vanilla JavaScript (ES6+), CSS3 (CSS Variables, Flexbox/Grid, адаптивний інтерфейс, світла та темна теми)
- ReportLab (генерація актів робіт та фінансових звітів у PDF з підтримкою кирилиці)
- openpyxl (експорт транзакцій у формат Excel)
- Pillow (перевірка валідності та оптимізація фотографій)

## Запуск

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Скопіювати `.env.example` у `.env` та заповнити `SECRET_KEY`.
Для роботи без MySQL виставити `USE_SQLITE=True`.

```
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Тести:

```
python manage.py test
```

## Структура

- `main` — користувачі, гараж, заявки, чат, сповіщення, PDF-акти
- `search` — публічний пошук СТО
- `station` — публічна сторінка СТО, відгуки та фото
- `accounting` — фінанси, персонал, склад, постачальники
